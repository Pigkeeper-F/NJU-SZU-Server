# FBSH80 原始表规范化：首次方案草案 v1

日期：2026-10-27（Asia/Shanghai）。状态：供讨论，所有建议规则均未确认，未执行清洗。

目标：把本轮原始表整理为可供后续处理的规范数据表。本轮仅检查输入并提出方案，不进行商品级估算、比例回代或模型计算。首次草案单独保存，后续讨论应另存版本。

## 1. 材料与实际发现

本轮研究依据仅为用户指定的 `FBSH_1992_Afghanistan_练习样本.csv` 与 `数据来源与范围.txt`。没有联网、调用其他智能体、读取旧方案或核对答案。来源说明中的历史路径只是来源线索，本轮没有打开它们或原始 ZIP。因此，“与原包逐字段一致”是说明文件第9行的陈述，本轮不能独立复核。

下文“行”均指 CSV 文件行号，第1行为表头。已核实每条逻辑记录均占一行，所以数据记录1—80对应文件第2—81行。

- 数据有80条记录、13列、23个不同的 Item Code。每行记录一个地区、商品条目、要素、年份、单位下的 Value 和 Flag。
- 地区全部为 Afghanistan，`Area Code=2`，`Area Code (M49)='004`；`Year Code=Year=1992`；`Unit` 全为 `1000 t`。
- 六个要素及记录数为：5511 Production 21条、5611 Import Quantity 15条、5911 Export Quantity 12条、5074 Stock Variation 6条、5142 Food 18条、5521 Feed 8条。与说明第8行允许的要素集合一致。
- 文件为带BOM的UTF-8、逗号分隔、CRLF换行。含逗号的名称有合规双引号，例如第27行 `"Cereals, Other"`。81条逻辑记录（含表头）均为13列。
- 实际存在的规范化需求：全部80条M49编码含字面前导单引号，例如 `'004`；全部80条FBS商品编码也含字面前导单引号，例如 `'S2905`。应讨论在规范副本中去掉这一字符，同时保留前导零与字母S。BOM也是读取时需要正确处理的格式特征，均不等于数值内容错误。
- 未发现空白记录、空单元格、字段首尾空格、完全重复行、候选业务键重复、非有限值或无法解析的Value。本样本的代码—名称对应、FBS编码对应关系和年份双字段均未发现冲突。上述结论仅限本样本。
- `Value` 全以6位小数表示，范围为-11.000000至2370.000000；20条为零。2条负数均为Stock Variation：第45行商品2909与第50行商品2542，值均为-11.000000。它们不是已证实的错误，不应自动取绝对值、改零或删除。
- `Flag` 为E共30条、I共50条。两个文件没有提供标记含义表，不能据此判定哪些记录应该删除或降权。

需要注意的风险，不应写成已发现错误：

1. 来源说明第8、11行明确本样本是匹配记录中的前80条，不完整。23个商品与6个要素的138种可能组合中只出现80种，另外58种仅能称为“样本未出现”，不能称为58个应填补的缺失值。第79行Sunflower seed只有Production，第80—81行Cottonseed只有Production和Export Quantity。
2. 名称上类似汇总类与较细条目的记录并列。例如第29行Starchy Roots与第33行Potatoes and products的Production都为225，但商品代码不同。存在后续重复计量风险；正式层级及可加总关系没有随材料提供。
3. 零值、未出现记录和未来可能遇到的空值需要分开表达。当前没有空值，也没有充分依据补造商品—要素记录。
4. Stock Variation的正负号经济含义、E/I标记定义、完整食物平衡关系、官方代码字典与数据库发布版本，均不能从当前材料确定。不能用六个筛选要素强制配平或判断全库覆盖完整性。

## 3. 需要研究者讨论决定的事项

1. **编码表示是否采用R03。** 推荐只去掉M49和FBS字段中的字面前导单引号，代码继续用文本保存。理由：使机器读取更直接，同时保存`004`的前导零、FBS的S前缀和不同代码体系。单引号最初为何产生，材料未说明，待确认；本草案不把它判定为源文件造假或损坏。
2. **规范表结构与类型。** 推荐保留原13字段名称和长表布局，额外增加`source_record`，在文件级清单保存来源与规则版本；Year用整数，Value用精确十进制，其余字段按文本。理由：减少改名、转宽和删冗余列带来的解释变化，方便逐行复核。若后续系统要求不同列名、宽表或必须转换单位，需另行提供接口契约，当前待确认。
3. **未出现组合是否补齐。** 推荐本阶段不补行、不填零、不插补。理由：样本由顺序截取产生，未出现记录不能解释为原数据库零值或漏报。若研究者确需完整覆盖，需另行提供完整数据和范围，当前待确认。
4. **E/I和Stock Variation符号如何解释。** 推荐本轮保留原标记与原符号，不据此筛选或调整值。正式标记字典和库存正负号定义均待确认；本轮不外查、不猜释义。
5. **商品层级与业务验收范围。** 推荐全部23个条目保留，本轮验收采用结构、类型、映射和逐行数值不变，不要求汇总等于细项之和，也不要求平衡等式成立。理由：材料没有正式层级及完整平衡项目。需建立这些业务核验时，正式商品层级、平衡式及允许误差均待确认，属于后续扩展。

以上为集中讨论清单，不构成对规则的确认。当前材料足以先形成这一完整草案，不必先补充信息才能讨论。
