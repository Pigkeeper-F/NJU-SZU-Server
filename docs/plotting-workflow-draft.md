# 绘图工作流（讨论草稿 v0.1）

## 定义

根据研究问题和已明确版本的数据生成展示规律的图，帮助观察趋势、分布、差异、关联及不确定性。图形表达与统计结论应有数据和方法依据。

## 输入

- 必需：待绘制数据及字段/单位、希望观察或表达的问题。
- 可选：图类型、比较对象、时间/空间尺度、分组、聚合方法、不确定性、风格及导出尺寸/格式。
- 数据审核状态、缺失/异常标记、现有参考图和投稿要求（如有）。
- 问题或绘图口径不明确时，先提供图形与汇总方案供对齐。

## 执行

1. 理解问题并核对数据版本、字段含义与可用范围。
2. 提出图类型、轴、分组、聚合、误差表示及筛选方案。
3. 按确认方案生成绘图数据，记录统计变换、缺失处理和筛选条件。
4. 绘制预览，标明单位、样本量、图例、必要的数据来源与审核状态。
5. 检查数值对应和视觉表达，展示可观察规律及局限，交人工审阅。
6. 按反馈调整并导出成图、绘图数据、代码和说明。

## 交付

- 展示图及可选 PNG/SVG/PDF 等格式，按用途确定尺寸与分辨率。
- 绘图数据、可复现代码/配置、原始输入版本与变换记录。
- 图注：变量、单位、样本范围、筛选/聚合方法、不确定性含义与来源。
- 简要规律说明、未确认异常及审核状态。

## 检查

- 图中数值与绘图数据一致，轴、图例、单位和分组正确。
- 聚合、排序、对数变换、缺失排除及误差条含义明确。
- 坐标截断、色阶和图形选择不会误导；标签可读，颜色区分有效。
- 统计显著性仅来自已执行且适用的检验，关联图不直接推导因果。
- 输出在目标尺寸下可读，代码和配置能复现。

## 异常

- 字段缺失、单位不明或数据不足：说明不能支持的表达，返回补充或调整方案。
- 数据未经审核：以探索预览状态交付，正式采用条件由审核政策确定。
- 出现异常点或趋势不符合预期：保留真实结果并标记，回查数据/计算；调整展示有记录。
- 图形拥挤或差异难辨：提出分面、尺度或图类型调整，并说明其影响。

## 需对齐内容

1. 首期绘图重点是探索规律、计算验收，还是论文成图？
2. 默认支持哪些图：趋势、分布、分组比较、散点关联、空间图等？
3. 系统能否推荐聚合与统计方法，哪些需要用户确认？
4. 未经审核的数据能否绘制探索图，正式导出是否必须审核通过？
5. 导出格式、风格模板、图注与规律解读需要达到什么程度？
