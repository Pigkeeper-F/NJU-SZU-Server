# 平台自动数据获取验证 · 2026-10-20

## 已安装流程

直接讨论 → 形成并审核下载方案 → 按方案开始下载 → 后台自动获取 → 人工检查 → 按需交接清洗。

- FAOSTAT TM 自动从官方目录定位全库ZIP，再按方案年份及明确条件筛选；无需用户找链接或填写下载配置。
- 方案已含公开文件地址时，使用同一任务接口获取，每批最多5个。其他数据库自动定位/认证接口需单独接入。
- 流式写盘，单个原始文件、筛选结果及本地清洗交接支持2GiB。手动上传与兼容小文件弹窗仍为20MB。
- 保留原包、冻结方案、来源和更新时间、实际字节数、SHA256、CRC、筛选行数、脚本和配置。输入不补零、去重、换算或合并。
- 进度、停止、恢复查看、同方案继续、官方缓存复核复用和原包/结果/报告下载均已接线。

## 验证证据

1. `tools/test-source-transfer.js`：21MiB流式下载、带验证器的Range续传、服务器忽略Range时重新下载、公网DNS检查、官方跳转限制、HTML拒绝及大小上限通过。
2. `tools/test_faostat_filter.py`：7项测试通过，验证年份筛选、前导零/负值/Flag保留、指标限制、无匹配失败、异常行不跳过、不安全成员拒绝和CRC损坏失败。
3. `tools/test-faostat-download.js`：使用42,060,560字节本地测试ZIP，按年生成35,040,232字节CSV；来源/哈希、缓存复用、原包不覆盖、服务重启恢复、主动停止、通用大文件任务和超过20MB的清洗交接通过。
4. `tools/test-download-routing.js`、`tools/test-source-download.js`、`tools/check-contract.js`通过。旧通用小文件下载兼容，未审核或修改方案仍不能执行。
5. 独立localhost:18126真实网页验证：新建标明测试数据的任务，保存/审核方案，点击平台执行按钮直接进入自动下载任务，无地址弹窗；从120,000行筛出2024年100,000行。结果区显示原包、CSV和报告下载按钮。测试数据及任务目录与18125隔离，不启动用户真实研究任务。
6. 通过本地HTTP下载测试CSV并复核35,040,232字节和SHA256一致；异源请求被403拒绝。页面刷新恢复同一已完成任务，未重复启动。
