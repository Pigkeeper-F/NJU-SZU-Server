# 文章撰写与修改工作流（讨论草稿 v0.1）

> 九步研究流程 · 环节⑥。对应业务流程表「文章撰写与修改：组织研究内容，形成论文」。
> 上游产物：环节②的问题陈述、环节③④⑤的图表 / 结果数据 / 代码与说明。
> 下游：环节⑦投稿前的核验与投稿。
> 目标期刊在**本环节开始时由使用者填写**，据此约束章节结构、篇幅、引用与图表规范。

## 定义

把上游的问题陈述、方法、结果数据与图表组织成一篇符合目标期刊要求的完整稿件，
并通过逐轮修改收敛到逻辑闭环、结论均可溯源的终稿。稿件与图表、参考文献成套交付。

## 输入

- 必需：目标期刊名称（使用者填写）；上游全部已通过审核环节的产物 —— 问题陈述、
  方法与运行记录、结果数据、图表文件与图注、参考文献条目。
- 可选：目标期刊的作者指南或格式模板（已下载的 PDF / 规范文件）、作者与单位信息、
  基金与致谢信息、数据与代码可用性声明要求、补充材料要求。
- 上游产物缺失时不得凭空补写：缺哪一项就明确列为待补，并阻塞该章节的成稿。
- 未填目标期刊时，先请使用者填写，或退化为通用结构并明确标注「未按目标期刊约束」。

## 执行

1. 读取目标期刊要求，提取结构骨架、篇幅、图表与引用规范，形成「写作约束清单」。
2. 汇总上游产物索引：每张图、每组结果数据、每条结论分别来自哪个环节的哪个文件。
3. 按结构起草初稿：引言（问题与空白）、方法（可复现描述）、结果（图表 + 数字）、
   讨论（与已有工作对比、局限、贡献）、结论、参考文献、声明类章节。
4. 逐句标注结论的来源：每条结论必须指向某张图、某组数据或某篇文献；无来源的句子删或改写为假设。
5. 图表插入与编号：按目标期刊规范排版，编号、标题、图注、坐标轴单位一致。
6. 参考文献整理：统一引用样式，核对正文引用与文献表双向齐全。
7. 自检：数字一致性（正文数字 = 图表数据 = 结果文件）、术语一致、图表编号连续、引用可解析。
8. 逐轮修改：每轮留存版本与修改说明，标明改了什么、为什么改。
9. 交人工审阅，按反馈重写受影响段落，再做一次全文一致性自检。

## 交付

- 稿件源文件：`manuscript.tex`（主稿）、`references.bib`、图表目录 `figures/`。
- 可读副本：`manuscript.md`（供快速通读与评审）。
- 图表与图注（与主稿编号一致）。
- 写作约束清单（本次按哪个期刊的什么规范写）。
- 结论溯源表：每条结论 → 支撑图 / 数据 / 文献。
- 修改记录：每轮改了什么、依据是什么。
- 自检报告：数字一致性、编号连续性、引用完整性、待补清单。

## 检查

- 全文结构与目标期刊要求一致；未满足项已列出。
- 每条结论都有数据、图表或文献支撑；无凭空断言。
- 正文数字与图表、结果文件完全一致（逐项核对，不抽样）。
- 图表编号连续、图注可独立读懂、单位与量纲齐全。
- 参考文献双向齐全：正文每条引用都在表中，表内每条都被引用。
- 方法描述足以让同领域研究者复现。
- 版本记录完整，每轮改动可回看。

## 异常

- 上游产物缺失：列出缺口与影响范围，先完成可写的章节，缺口章节标注待补。
- 目标期刊未填：按通用结构起草并显著标注，不假称符合任何期刊。
- 图表与正文数字对不上：以数据文件为准，修正正文或图表，并记录原因。
- 篇幅超限：先压缩讨论与方法细节，再压缩结果描述，说明压缩了什么。
- 目标期刊要求与已有产物冲突（如必须公开数据但数据受限）：列出冲突，给出改写或说明的方案。
- 生成内容与作者原意冲突：交人工裁定，不自行改写核心论点。

## 需对齐内容

1. 目标期刊从哪一级获取规范：手填刊名后自动匹配作者指南，还是需要使用者上传指南文件。
2. 稿子以英文还是中文为主；是否需要中英双版本。
3. LaTeX 模板用哪一个（出版社模板 / 通用 article），引用样式用 BibTeX 还是 BibLaTeX。
4. 作者、基金、伦理与数据声明这些信息是否由本环节自动生成占位符。
5. 修改轮次是否需要固定节奏，还是由使用者随时发起。
6. 补充材料（附录、额外实验）是否纳入本环节产物。
