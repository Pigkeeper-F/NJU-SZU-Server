# 从已有成果开始文献处理

文献任务可以分段执行。已有检索、去重、正文、补充材料和处理结果可以作为后续任务的输入，无须为了提取或核查重新检索。

## 在页面上操作

1. 找到保存了所需成果的文献任务，点击“从已有成果开始”。
2. 选择本次的开始和结束阶段，再勾选文献。小样本核查可选 5 篇；候选或已下载文献不自动等于符合研究纳入规则。
3. 创建独立的分段任务。创建只准备本地输入，尚不执行检索、下载或模型提取。
4. 从提取开始时，在字段面板讨论、填写并确认表头含义和单位，再明确启动。开始于校验或导出时，沿用原提取字段版本，核对执行范围后再启动。
5. 对照正文及实际补充材料核查首批结果。自动校验完成不等于数值经过人工核查。

| 开始阶段 | 必须已有的成果 | 本次复用的工作 |
| --- | --- | --- |
| 提取数据 | 选中文献的已保存、可读取且身份匹配的正文 PDF，以及已保存的有效补充材料 | 检索、去重、全文获取 |
| 校验结果 | 与本次材料和字段版本对应的逐篇提取结果 | 上述各项及提取 |
| 导出结果 | 对应的提取和校验结果 | 上述各项及校验 |

结束阶段可以选开始阶段或其后的阶段。页面会说明每篇不满足前置条件的原因，不会为了凑足篇数把缺失前置成果当作已完成。

## 已完成成果的保护

- 每次分段执行建立独立记录，保存来源任务、文献编号、阶段范围和输入文件校验值。
- 只复制选中文献所需的本地成果，不重新请求原网站下载。来源记录、原提取和原导出文件保留。
- 从提取开始时不带入旧提取结果，防止把旧字段或旧网页正文的结果当成这次 PDF 提取结果。
- 从校验或导出开始时，只允许复用能核对材料和字段版本的前序结果。
- 正文、补充材料未齐或不可读时保留提示；摘要不作为完整正文，已排除的历史导航链接不作为待提取附件。
- “材料补齐”任务仍只负责正文和补充材料，不会因材料已齐而自动进入提取。

## 字段与结果对应

字段面板的“关联条件键”用于保留结果数值对应的指标、处理组、时间点等条件。现执行器会合并所确认字段的条件键供每条结果使用；未讨论确认的科学口径不自动填写。字段仍需人工确认，旧任务的审核状态不会代替新任务的确认。

PDF 提取输入带有实际 PDF 页序标记。若文本超过输入容量，结果会标记部分覆盖，不能仅因文件已下载完整就声称已经提取全文全部内容。

## 本轮边界

这次只补入口和复用机制，不代替研究者选择纳入文献、确认表头，也不启动新的真实提取。
