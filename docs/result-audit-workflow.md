# 结果核查与问题定位

## 定义

在每次计算完成后，读取该计算任务的输入、代码、运行日志与输出结果，按研究者给出的检查标准分析异常并定位可能的原因。核查结论必须绑定具体的计算运行版本。发现问题时回到计算模块修正、重跑，再对新结果复验。

## 输入

- 本任务计算模块上传的代码与输入文件，以及每次运行产生的结果、日志和报告。
- 研究者提出的预期范围、守恒关系、基准结果、抽样检查办法等；未提供时可提出候选检查项，但不能将其视为已确认标准。

## 执行

核查依据有两个入口：点击“讨论核查原则”，和 AI 确定检查项后，在“查看 / 编辑核查原则”大弹窗中保存、确认；或者点击“上传核查标准”，上传已有标准或参考文件。上传标准独立存放在 reference 目录，不混入计算输入。支持 MD、TXT、PDF、DOCX、CSV、TSV、Excel、JSON，每个文件最多 20MB；若本机工具不能解析文件，必须说明并请研究者提供可读版本。

确认的原则按本模块保存并保留历史版本。AI 提取的候选原则须由研究者确认；已有标准文件可直接作为核查依据，冲突、歧义或版本未指定时先询问。点击“核查计算结果”前，需要已有计算输出，并具备已确认原则或上传的标准文件。

1. 先指出所检查的运行版本与文件；若有多次运行，明确选择哪一次。
2. 检查输出文件结构、数量、缺失、异常值、单位、边界与适用的汇总或守恒关系。
3. 对异常追溯输入数据、参数、字段映射、代码路径和运行配置，列出证据、可能原因与尚未确定的部分。
4. 与研究者讨论需要回到哪一步修改。核查模块只读，不在这里悄悄修改输入或代码。
5. 修正后重新运行计算，并对新版本复验；旧核查结论保留但不自动适用于新结果。

## 交付

- 在对话中给出按运行版本整理的检查结果、问题清单、定位依据、建议回退步骤与待人工确认项。
- 未实际检查过的文件、数值或关系不能声称通过。
