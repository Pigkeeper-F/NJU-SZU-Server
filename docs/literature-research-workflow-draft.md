# 文献调研工作流（讨论草稿 v0.1）

> 九步研究流程 · 环节①。对应业务流程表「文献调研：检索、阅读和整理已有研究」。
> 与能力节点「文献挖掘」（为计算模块做参数提取）是**两个独立环节**：本环节产出综述与研究空白，
> 底层可复用文献挖掘的检索 / 跨来源去重 / 全文获取管线，但产物口径与验收标准不同。

## 定义

围绕研究主题系统检索、阅读并整理已有研究，产出一份可溯源的文献清单与综述要点，
并明确指出该方向上的研究空白。结论必须能回溯到具体文献（作者 / 年份 / 来源）。

## 输入

- 必需：研究主题或待调研的问题；目标时间范围（默认近 5 年）；来源范围（默认可用来源）。
- 可选：已知的关键文献、目标期刊的常见综述范围、语言与地域限制、篇数上限。
- 待调研方向是否已有初步假设（若有，调研需同时给出支持与反对的证据）。
- 主题过宽或无法构造检索式时，先给出候选检索式与边界供确认，不擅自扩大范围。

## 执行

1. 拆解研究主题为检索维度（核心概念 / 方法 / 对象 / 应用场景），列出同义词与上下位词。
2. 构造并记录检索式（每个来源一份），标注检索日期与来源。
3. 逐来源检索首批候选，按题录去重（同 DOI / 同标题 / 同作者同年份），记录被排除项及原因。
4. 按相关度初筛，标记必读 / 略读 / 排除，并保留排除依据。
5. 获取全文；仅拿到题录的标记为「仅题录」，不据此写实质结论。
6. 逐篇抽取结构化要点：研究问题、数据来源、方法、结论、局限。
7. 横向归纳：共识点、分歧点、各方法的能力边界、尚未解决的问题。
8. 从分歧与未解问题中定位研究空白，给出可溯源依据。
9. 交人工审阅，按反馈补检或调整归纳，再定稿。

## 交付

- 文献清单（CSV / JSON）：题录、来源、检索式、获取方式、必读标记、排除理由。
- 逐篇要点表：每篇的研究问题、数据、方法、结论、局限。
- 综述要点：共识 / 分歧 / 能力边界三段式，每条结论附出处。
- 研究空白清单：每条含「空白描述 + 支撑依据（哪几篇的什么结论指向它）+ 可检验方向」。
- 调研日志：检索式、日期、各来源命中与去重数量。

## 检查

- 检索式已记录且可复跑；每条结论都能定位到具体文献（作者 / 年份 / 来源）。
- 覆盖了主题的主要工作；近 5 年工作与高被引综述均在列。
- 至少指出 1 条具体空白，且不是「研究较少」这类空泛表述。
- 分歧被如实记录，未把个别论文的主张当作领域共识。
- 仅题录的文献未被用于支撑实质结论。
- 排除项与排除理由可查。

## 异常

- 检索无结果或结果过少：先放宽检索式与时间范围并记录改动，再提出是否换来源。
- 主题过宽导致结果发散：提出收窄到具体子问题的方案与代价，交人工确认。
- 全文获取失败（付费墙 / 验证码 / 仅摘要）：标记获取状态，说明该篇的结论可信度受限。
- 来源之间结果冲突：并列呈现，标注各自条件与证据强度，不强行取舍。
- 无法定位任何研究空白：如实说明该方向可能已充分研究，并给出替代切入角度。

## 需对齐内容

1. 本环节与「文献挖掘」能力节点共用到什么程度：仅共用检索能力，还是共用全文与去重产物？
2. 调研模式下的默认来源集合与篇数上限是多少？
3. 研究空白的表述与验收由谁最终确认（导师 / 组内 / 本人）？
4. 综述要点是否需要按目标期刊的综述结构预先生成？
5. 全文受限比例多高时可接受只做题录级整理？
