# 文献挖掘：小样、正式与其他主题分别建任务

## 操作

在当前项目的“文献挖掘”面板，点击 **＋ 新建文献任务**：

1. 填名称，例如“肉鸡热应激 · 正式检索”。
2. 选“小样测试（每来源10条）”或“正式检索（到可访问末页）”。正式模式需明确选择。
3. 其他主题选“空白开始”；沿用小样方案选“复用当前规则和表头”，并重新核对。
4. 点“创建并核对设置”，讨论或编辑规则后，明确点击“确认配置并检索”才开始。

已有检索记录的任务不能直接用检索按钮重新覆盖。对原候选继续取得材料、提取或导出，使用原任务的继续操作；正式检索与新主题新建独立任务。

## 保留与隔离

- 当前项目不变，通过“当前文献任务”下拉切换小样、正式和其他主题。
- 讨论、规则文档及历史、未发送内容、字段、文件会话和原检索绑定按文献任务分开保存。
- 复用只复制规则与表头草稿，不复制候选、材料、提取结果、原文件会话或审核通过状态。复用的文档作为草稿，字段仍须在提取前确认。
- 创建和切换不自动检索、续跑、下载或提取；切回已执行任务时只读其保存状态。
- 有正在执行的工作时禁止切换；本地保存失败则保持原任务。切换中断保留恢复标记，刷新后优先恢复旧上下文。
- 顶部“备份”包含独立文献任务目录、检索绑定和字段讨论。它仍不包含服务器原材料、API Key或数据库登录会话。

## 面板显示

已执行任务默认收起“任务详情与全部成果”，外面保留当前任务、关键进度、材料缺口提醒，以及参数明细表和文献表的下载入口。展开后，可分别打开“检索与执行设置”和“材料、过程文件与历史记录”；全部导出文件仍在详情中。新任务草稿默认展开设置，方便核对。

登录或字段确认等需要处理的事项，以及运行中的“停止”按钮，始终在整体折叠区外显示。折叠操作不会停止任务、删除文件或触发执行。展开状态按检索记录在当前页面保留，轮询不会强制折回。

文献区默认字号为 20px。标题旁的 **A− / A＋** 可在 18–28px 间调整，刷新后保留选择；文献区的规则卡、审核操作、消息和输入框同步调整，其他模块保持原字号。

任务面板右侧保留纵向滚动条。展开长设置和文件列表后，可在面板内用滚轮、拖动滚动条，或点面板后用方向键 / Page Down 查看下方；下方讨论和输入区域保留空间。同一任务的状态刷新保留滚动位置和手动展开状态。

“文献表条数”表示导出的文献记录数；“已获取正文”“PDF”“网页正文”分别显示实际材料数量。完成导出时仍会显示材料缺口，参数行数单独计算。

文献任务依赖原浏览器、原网址的本地记录，请沿用原访问地址。已有服务器任务和材料目录不因新建而删除。
