# 绘图完整流程验证（2026-10-20）

## 交付

- 上传 CSV/TSV/Excel/JSON/TXT，选择本次输入；本机 Codex 只读讨论数据和图形要求。
- 唯一绘图方案弹窗支持候选提取、编辑、人工审核及版本历史；未审核修改不能生成。
- 显式执行生成图片、绘图代码、绘图数据和说明；首次读取或生成时准备项目 Python 绘图依赖。
- 版本区提供预览、点击大图、文件下载和针对某版的修改讨论；每次生成另存，不覆盖旧图。
- 服务器独立记录输入 SHA-256、方案版本、模型和关联历史版本，失败、停止和中断均保留真实状态。

## 自动检查

- `test-plotting.js`：审核和文件边界、只读/执行沙箱、真实 Matplotlib PNG/SVG/PDF、可下载代码、版本保留、无图失败及重启恢复。
- `test-calculation-plan.js`：新增绘图审核与未审核修改阻止执行，原修改计算回归通过。
- `test-codex-login.js`、`test-codex-models.js`、`test-start-workbench.js` 通过。
- 修改脚本语法、契约检查和差异空白检查通过。
- HTTP 实测拒绝缺少审核方案的执行、越界文件与伪 PNG，历史接口返回正确结构。

## 浏览器与真实模型验证

在独立18126浏览器来源使用 `plotting-demo.csv` 的4行界面验证数据，未修改用户18125浏览器任务：

1. 上传后只读对话正确识别 year/value、4行及2020–2023，未生成文件。
2. 手写并审核方案v1，真实调用当前默认 `gpt-6.1-sol`，生成蓝色实线圆点 PNG/SVG/PDF、plot.py、plot-data.csv、requirements.txt、README及检查记录。
3. 浏览器实际下载 plot.py；用下载代码与下载的绘图数据，在独立目录重跑，重新生成PNG/SVG/PDF。
4. 修改意见指定橙色虚线方点及新标题，先只读讨论，再由AI提取候选方案；审核v2后真实生成第二版。
5. 两版均完成、模型标识正确、输入SHA一致，第二版关联第一版；首版代码及图片仍存在，历史选择可来回切换，刷新仍能恢复。

这组数据仅用于验证软件功能，不代表科研结论。图片的科学表达、统计口径和正式采用仍由研究者按自己的数据和方案核查。
