# 开发交接说明

本文件原为 2026-10-12 独立交接包说明。2026-10-14 合并后，源码已进入主 Git 项目；原项目独有的 SOC 流水线、流程图等资料继续保留。当前行为以源码和根目录 README 为准。

## 构建方式与代码入口

原生 HTML/CSS/JavaScript 前端 + Node.js 本地 HTTP 服务，无前端构建器或第三方 npm 依赖。页面加载顺序由 index.html 固定。

| 文件 | 职责 |
|---|---|
| js/store.js | 模块类型、状态、依赖链、消息、事件订阅与本地保存 |
| js/tasks.js | 独立任务切换、按模块保存规则、候选规则提取、规则弹窗和历史版本 |
| js/codex.js | 模型选择、会话、上传、任务轮询、直接运行、核查与回退入口 |
| js/chat.js | 记录/对话、消息上下文、把当前模块确认规则传给 AI |
| js/tabs.js、sidebar.js、workspace.js | 模块导航与工作台布局 |
| js/api-keys.js | API 配置界面与浏览器保存 |
| server.js | HTTP、静态资源、API 代理、模块工作流提示、Codex 路由 |
| tools/codex-bridge.js | Codex app-server 协议、文件目录、只读/执行范围、任务生命周期 |
| docs/*workflow*.md | 服务端读取的模块工作流依据；这些文件属于运行依赖 |

## 已实现的调整

1. 新建任务，隔离各任务模块和对话。
2. 从“总结全部对话”改为明确保存研究者确认的执行规则；AI 提取只写候选草稿。
3. 大弹窗编辑、确认与历史版本；清洗、修改计算、核查原则按模块分别保存。
4. 计算为直接运行和按规则修改两条路径；每次运行使用独立输出目录。
5. 核查读取计算的输入、代码、输出和日志；可先讨论原则或上传现成标准。
6. reference 独立存放标准，input 存放原始数据与代码，output 存放每次结果。
7. 核查发现可带回计算讨论；新计算结果提示重新核查。

## 接口与数据

/api/codex/status、session、files、upload、run、job、cancel、download 对应连接、会话、文件与任务操作。具体请求字段以 server.js 与 js/codex.js 为准。上传上限 20MB；组别 input/reference；下载支持 input/output/reference。核查会话复用当前任务的计算会话。

浏览器键：research_tasks_v1、research_task_state_<id>、fa_state_v1、research_codex_tasks_v1；API Key 使用 research_api_keys_v1。完整任务迁移尚未产品化，需要浏览器状态与服务端文件建立一致关联，不能只复制 .workbench 就认为迁移成功。

服务端运行状态目前保存在内存，重启后不能续接原运行记录；文件保留。规则和模块上下文有长度截断，长讨论需核对规则完整性。历史核查结论不会自动适用于新的运行。

## 接手后的优先事项

- 先按 README 启动，创建练习任务并跑通自身账号与环境。
- 用正式数据验证清洗、修改和核查完整链条，确认科学口径。
- 增加任务导入/导出、运行记录持久化、明确选择核查运行版本。
- 完善长对话规则提取、规则与输出的版本绑定、定位证据和重跑范围。
- 对照当前源码清理早期设计稿和用户指南中的过时描述。
- 当前只监听 127.0.0.1；多人远程部署、账号权限和服务运维尚未实现，不能直接当公网产品使用。
