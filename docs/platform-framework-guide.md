# 平台框架速查（给 AI 助手的全局视图）

> 这份文件回答"这个平台是什么、有哪些模块、我现在在哪、下一步去哪"。
> 具体某个模块怎么做，以该模块自己的工作流文档为准；这里只讲全局结构与跨模块关系。
> 事实来源：`js/store.js` 的固定工作台定义、`js/tabs.js` 的模块链、`server.js` 的 `WORKFLOW_FILES`。

## 一、平台是什么

一个本地运行的研究工作台（`http://localhost:8123/`）。研究者按主题准备好资料，交给模型计算，再核查与审核。平台自己不做科学判断，负责**组织流程、留痕、执行与检查**；需要科学判断的地方一律回到研究者确认。

## 二、七个固定入口（界面左侧，顺序固定）

| 序号 | 模块 | 作用 | 前提 |
|---|---|---|---|
| 01 | 下载数据 | 按确认规则抓公开数据文件 | 无 |
| 02 | 数据清洗 | 固定 CSV/TSV/Excel 检查、冻结脚本执行、独立核验 | 无 |
| 03 | 文献挖掘 | 五库检索 → 三态筛选 → 全文 → 提取 → 校验 → 导出 | 无 |
| 04 | 模型调整与计算 | 直接计算 / 修改计算 | 需先选计算方式 |
| 05 | 绘图 | 按确认方案出图 | 需先选计算方式 |
| 06 | 结果核查与定位 | 对计算结果做核查 | 需先选计算方式 |
| 07 | 人工审核 | 人工签署与证据整理 | 需先选计算方式 |

前三项是**并列的准备路径**，互不依赖，按任务需要选一条或几条；三项都汇入「模型调整与计算」。
没有哪个模块是"必须先做完"的——除了 05/06/07 需要先确定计算方式。

## 三、任务与工作区（两层，常被混淆）

- **任务（Task）**：左侧「任务」区切换，一个研究项目一个任务。任务之间数据隔离。
- **工作区（Workspace）**：同一任务内，每个模块可以有多个并行工作区（例如"小样测试"和"正式检索"分开）。文献模块顶部「当前文献任务」下拉就是切换工作区。
- **新建 ≠ 覆盖**：新建工作区不影响已有工作区的讨论、候选和材料。要看旧的用下拉切回或「历史任务」找回。

## 四、跨模块交接

- 文献挖掘 → 清洗/参数更新：提取表经人工审核后交接，只复制数据表，不带 PDF/XML。
- 下载数据 → 数据清洗：下载完成后交接批次，清洗模块只处理当前输入文件，历史文件不自动合并。
- 计算 → 绘图/结果核查：计算产生新运行结果时，先前的核查结论**不自动适用**，需按新版本重核。

## 五、三条贯穿全平台的规则（回答任何模块都要遵守）

1. **执行前确认**：涉及科学判断（纳排标准、字段含义、单位、缺失/插补策略）必须先由研究者确认；AI 可以提建议并标注假设，不能把建议当已确认。
2. **证据优先**：报告"完成/通过"必须有实际产物（文件落盘、校验记录、CSV 行数）。没有证据就说"未执行"。
3. **能力边界**：API 对话没有文件读写、联网、代码执行、模块操作工具。只有本机 Codex 模块（清洗/计算/绘图执行场景）能读写文件。不能声称已下载、已读取未提供的文件、已运行计算。

## 六、常见疑问的正确答法

- **"我该从哪开始？"** → 看研究者手上有什么：只有主题 → 文献挖掘；有原始数据 → 下载/清洗；有代码和数据 → 直接计算。不要一律说"从文献挖掘开始"。
- **"某个模块可以跳过吗？"** → 可以。三个准备路径互不依赖，只走需要的。
- **"这两个模块能同时做吗？"** → 任务内模块可并行讨论，但同一模块的执行有忙态保护；跨模块的交接需要前一步产物先确认。
- **"我的数据会不会丢？"** → 浏览器记录 + 服务端 `.workbench/` 文件分别保存；新建工作区不删旧数据；备份/恢复在左侧「任务」区。
