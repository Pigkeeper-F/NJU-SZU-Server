# 研究工作台简易使用指南

## 1. 打开工作台

在项目目录打开终端，运行：

```bash
npm start
```

浏览器打开 [http://localhost:8123/](http://localhost:8123/)。使用期间保持服务运行；在启动服务的终端按 `Ctrl + C` 可以停止服务。

## 2. 使用 AI 助手

所有模块默认使用本机 Codex，无需填写 API Key。在终端运行 `codex login` 并用 ChatGPT 账号登录；进入模块后点击“检查连接”。每个模块的“模型”下拉框可独立选择当前账号返回的可用模型，留在“默认”则使用账号默认模型。仍需联网，并使用账号的 Codex 额度。数据清洗和计算模块支持上传文件与执行；结果核查与定位模块只读地使用同一次计算的文件会话；其余模块提供文字指导。

各模块的“API 对话”模式使用以下配置：

1. 点击左侧栏底部 **添加 API**，选择 DeepSeek 或 OpenAI。侧栏折叠时点击底部 **＋** 即可。
2. 将对应供应商的 API Key 粘贴到输入框。
3. 确认模型名称，点击 **保存**。
4. 底部输入模式默认是 **AI 对话**；若手动切到记录模式，需切回 AI 对话才会请求模型。

密钥保存在当前浏览器。换浏览器或清除浏览器数据后，需要重新配置。不要把密钥写在聊天内容或导出的研究记录里。

也可点击左下角 **设置 → 模型** 管理多组模型配置：一个接口地址 + 一个 Key 为一组，组内可维护多个模型（模型名左侧 **▼** 展开切换，保存时当前模型自动入列）；点击 **测试连通** 会用表单当前值实测地址/Key/模型是否可用（留空字段回落服务端 `.env`），确认可用后再点 **保存**。

## 3. 创建模块并开始工作

顶部 **当前任务** 可切换不同研究任务。点击 **＋ 新建任务**，输入名称，并选择从“下载数据”、“数据清洗（已有原始文件）”或“计算（已有代码和输入数据）”开始。跳到后一步时，左侧会建立空的上游步骤以保持流程顺序；这不表示上游工作已完成。原任务的对话、文件会话和结果保留在原任务中，切回即可查看。旧版已有记录首次打开时归入“原有练习”。

顶部 **执行规则** 是当前任务的规则单。点击 **查看 / 编辑规则** 会打开较大的弹窗，可直接填写处理范围、输入、清洗步骤、异常处理、验收条件和输出。**AI 提取候选规则** 只尝试从当前模块对话找你明确决定采用的规则；输出仍是草稿，须由你删改并点击 **确认规则** 才会生效。旧版本可以从“历史版本”放回草稿重新修改；旧版“方案摘要”不会自动变成已确认规则。

数据清洗模块上传原始文件后，可在规则弹窗点击 **按规则执行清洗**。这会使用已确认的规则版本发起一次本机 Codex 执行，并要求交付清洗结果、代码和检查报告。没有已确认规则或未上传文件时不会启动。规则按模块分别保存，清洗规则不会自动变成计算修改规则。

计算步骤需要选择互斥路径：**直接计算**上传现有代码与输入数据，点击 **运行现有代码**，原代码不改；**修改计算**上传代码与数据，先在对话中讨论改法，再在本模块规则弹窗确认修改规则，点击 **按规则修改并计算**。两种路径都生成独立运行结果。然后添加 **结果核查与定位**，点击 **核查计算结果** 或在该模块对话，按具体运行版本检查输出并讨论问题来源；发现问题可返回计算模块修改或重跑，再核查新结果。

首次点击 **创建第一个模块**；之后在左侧研究流程中点击 **＋ 添加下一步**，按固定顺序添加模块。点击左侧模块即可切换，中间为当前模块的对话区。窄窗口可以使用左上角按钮展开或收起导航。计算方式只在选中计算模块、尚未确定方式时显示。

| 模块 | 可以告诉 AI 什么 |
|---|---|
| 下载数据 | 需要什么数据、来源、地区和时间范围 |
| 数据清洗 | 已有数据的字段、问题和希望采用的清洗标准 |
| 直接计算 / 修改计算 | 现有代码、输入数据、运行入口；修改路径另需明确代码变更规则 |
| 结果核查与定位 | 要核查的运行版本、预期范围、异常现象和定位线索 |
| 参数更新 | 要更新的参数、旧值、新值及来源 |
| 活动数据更新 | 新旧数据范围、字段和希望采用的合并方式 |
| 文献挖掘 | 研究主题、筛选范围和要提取的参数 |
| 人工审核 | 待审成果、检查报告和验收标准 |
| 绘图 | 数据字段和希望观察的趋势、差异或关联 |

不必一次提供全部信息。AI 会依据当前模块工作流，帮助你补齐输入、讨论规则、整理步骤、交付说明和检查项。涉及尚未确定的规则时，先与 AI 对齐再继续。

例如，在“文献挖掘”里输入：

> 我想研究中国农田土壤有机碳的变化，提取文献年份、地点、作物、施肥处理和 SOC 数值。请先帮我拟定检索范围与筛选规则。

或在“数据清洗”里输入：

> 我有一份年度数据，包含地区、年份和用量。存在重复记录、缺失值和单位不一致，请先帮我整理清洗规则和需要确认的问题。

数据清洗与计算的本机 Codex 模式支持读取上传文件并执行处理；结果核查与定位共享计算的文件会话，但只读分析。其余模块的本机 Codex 与 API 模式提供文字指导。各模块对话独立，必要时请提供需要衔接的上游成果摘要。

### 上传文件并实际清洗

1. 在“数据清洗”中选择 **本机 Codex**，点击 **选择文件** 上传 CSV、TSV、Excel、JSON 或 TXT 文件（单文件最多 20MB）。浏览器选择文件后，副本会保存到本地服务的任务目录。文件列表默认隐藏，点击 **文件与结果 ∨** 以浮层查看；再次点击、点击空白处或按 `Escape` 收起。上传完成后列表自动收起，不占用对话区高度。
2. 底部切换 **AI 对话**，上方选择 **查看数据 / 拟方案**。说明目标、数据范围、已有清洗步骤和项目特殊要求；验收标准可选。Codex 可以实际读取文件并分析，此模式不能写入清洗结果。
3. 与 Codex 对齐方案后，选择 **执行已确认步骤**，发送明确指令，例如“按刚才确认的全部列完全重复规则去重，保留第一次出现，其他值不变；输出 CSV 和检查报告”。
4. 展开执行进度；需要中止时点击 **停止任务**。完成后展开 **文件与结果**，点击“结果”文件链接下载数据、脚本或报告。部分失败或停止后的文件需检查后使用。

输入副本与每次运行输出分开存放，原电脑文件不会被直接修改。文件保存在项目 `.workbench/`，不会提交到 Git；它们可能包含研究数据，请按项目要求管理。此版本使用 Codex 的写入沙箱和任务范围提示，不是完全隔离的文件读取环境。网络工具与越界审批不开放；已有依赖不足时助手会说明。

## 4. 记录与保存

- **记录模式**：只保存笔记，不请求 AI。
- **AI 对话**：发送内容并获取当前模块的 AI 回复。
- `Enter` 发送或保存；`Shift + Enter` 换行。
- 左侧 **工作记录** 可以集中回顾各模块对话。

任务列表、对话和规则自动保存在当前浏览器。当前精简界面不提供完整任务导出；重要对话和规则可自行复制备份，实际研究数据文件需另行下载保存。清除浏览器站点数据会清除任务列表和对话。

## 5. 常见问题

- **没有 AI 回复**：确认已选择 AI 对话并保持本地服务运行。本机 Codex 模式检查登录与连接；API 模式检查密钥、模型或网络。
- **服务重启后任务状态丢失**：已上传和输出文件仍保留，可点击“刷新文件”；运行中的任务需要检查已有结果后重新发起。刷新页面时，尚在同一服务中运行的任务会尝试恢复显示。
- **换浏览器后记录不见了**：记录和 API 配置按浏览器分别保存，使用原浏览器查看。
- **页面仍显示旧内容**：强制刷新页面；服务代码更新后，在原服务终端按 `Ctrl + C`，再运行 `npm start`。
- **AI 缺少之前的信息**：重新提供关键规则或成果摘要，尤其是在切换模块或对话较长时。

# 结果核查的依据

进入“结果核查与定位”后，可以点击“讨论核查原则”，再在上方“查看 / 编辑核查原则”的大弹窗中确认指标、阈值和通过条件；也可以点击“上传核查标准”直接提供已有标准。准备好计算输出和核查依据后，点击“核查计算结果”。标准文件在文件列表中标为“核查标准”，不会作为计算输入。
