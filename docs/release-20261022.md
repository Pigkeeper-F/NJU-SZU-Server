本次整理发布已有本地开发成果，便于协作者接着开发。程序源码、依赖声明、测试、接口契约和案例随仓库交付；运行时数据仍按各电脑独立保存。

## 本次代码

- 文献获取：正文优先 PDF，网页正文可作后备；补充材料保留原格式，逐篇登记保存、读取、缺失和复用状态。已有文件经身份及 SHA 核对后复用；明确选择跳过失败项后继续处理，其原因仍保留。
- 知网与下载窗口：保留真实点击、页面身份和窗口关系；按本次任务核验下载事件，不扫描用户下载目录猜测文件。文件与状态保存完成后清理本任务拥有的窗口，登录、验证及来源错误保留处理入口。
- 提取字段：弹窗支持讨论，点击“按讨论填入表格”后直接填写实际可编辑表格；最多 200 个独立字段，保留撤销和待确认事项。“核对表格并开始提取”提交当前字段给同一任务，只推进到提取，不受外部旧下拉框阻挡。
- 清洗结果：按主要结果、报告、问题与辅助文件分组，可切换历史运行并下载所选运行 ZIP；结果分组不改变原始文件或人工验收状态。
- 数据下载：修复 FAOSTAT TM 官方字典匹配、按方案筛选及交付；通用后台下载与兼容手动上传分别遵循自己的大小限制。下载、清洗和文献获取继续使用各自的执行入口。

## 启动与接手

1. 安装 Node.js 18+，克隆仓库并切换本次上传分支。
2. Windows 双击根目录 `start-workbench.cmd`，打开 `http://localhost:18125/`；命令行可运行 `npm start`。保持本地服务运行。
3. 页面账号门禁只用于本地演示，数据库与模型使用接手者自己的登录和权限。不要把服务公开到互联网。
4. 按案例说明先查看配置与结果，再决定是否执行新的检索、材料获取和提取。仅打开文件不会运行任务。

本机 `.workbench/`、`.venv/`、密钥、Cookie 和浏览器登录档案不入库。浏览器研究记录与本地服务器材料是两套状态；复制代码不能自动复制原电脑的工作现场。
