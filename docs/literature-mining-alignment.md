# 文献挖掘：已确认的输入与默认规则

本文件记录研究者在 2026-10-12 至 2026-10-13 对通用文献挖掘流程的确认。2026-10-19 本地整合已接入六阶段文献流水线，并保留已审核方案执行与清洗交接；两种入口的范围分别说明如下。

## 最小启动与阶段关口

- 候选检索只需研究主题。默认来源为 Google Scholar，可另选中国知网、万方、Web of Science 核心合集、Scopus 和 PubMed；按研究需要单选或多选。测试每来源最多10条；正式自动翻页到各来源可访问的末页，不设置候选数量上限。登录、验证、网络或来源访问限制会暂停，保存已有成果后等待「检查并继续」；来源限制不等于全部检索完成。检索结果的标题和片段只能用于初筛，不能当成已核实的论文摘要或全文证据。
- 年份、地区、语言、文献类型可选；正式数量默认100，需研究者确认，达到上限或明确末页时停止。模式和数量一并冻结，测试不会自行扩大到正式数量。
- 全文提取前，研究者须确认主题参数字段的含义和单位处理方式。若某主题需要专属硬性纳排规则，也须明确确认。SOC 规则仅在选择 SOC 示例配置时启用。

## 通用筛选与数据结构

- 仅将明确重复或明确不相关的候选自动排除；证据不足时标为“待全文核查”，不强行纳入。
- 文献表一篇论文一行：题名、作者、年份、DOI、来源链接、全文链接、检索日期、筛选状态与理由等通用 meta 字段。
- 参数明细表一个有出处的报告值一行，用论文 ID 关联；保存参数名称、原值、原单位、出处与适用条件。地点、处理、年份等条件按主题定义，不固定为 SOC 结构。
- AI 可提出主题参数候选字段，但字段名称、含义和单位处理须经研究者确认后用于全文提取。
- DOI/题名清单、链接和本地 PDF 是可选输入，与检索结果采用同样的查重、筛选规则；用户提供的材料不自动视为已纳入。全文无法合法获取时标为待补充，不绕过访问限制。

## 校验与导出

- 阻断：缺少论文 ID 或可追溯来源；参数行缺名称或原值；声明为数值的字段不是有效数字；字段不符合本次确认的结构；参数行无法关联文献。
- 待审核：缺 DOI、单位不明、疑似重复或异常值。不擅自补值、换算或删除。SOC 数值范围等科学阈值不作通用默认。
- 默认依据同一份已确认字段定义生成文献表与参数明细表，均导出 CSV 和 Excel。被排除文献仍保留筛选记录；校验失败的行另列错误报告；新结果不覆盖旧版本。
- 用户 Excel 模板可选；若提供，先核对并确认字段映射。SOC 模板的两张固定工作表与专属字段不直接套用到其他主题。

## 已接入的首批连接器（2026-10-15）

- 文献挖掘页面点击「从对话整理规则」后，本机 Codex 依据本模块对话及已批准文档生成候选运行配置；研究者一次核对并可修改，然后点击「确认配置并检索」。配置随任务保存为 `run_config.json`。对话本身不自动触发检索。
- 运行配置包含主题、默认检索式、各来源独立检索式 `sourceQueries`、来源、论文发表年份、地域、语言、研究类型、纳排规则、目标字段及每来源每批条数。各来源检索式留空时沿用默认；实际执行与延后规则按来源记录，不宣称未执行的筛选或全文提取。
- 2026-10-19 已扩展为 Google Scholar、中国知网、万方、Web of Science 核心合集、Scopus 和 PubMed 六来源。PubMed 通过 NCBI 官方 E-utilities 获取公开书目与摘要，通常无需登录；其他来源登录、验证码与机构权限要求交人工处理。失败不静默更换数据库。
- 首次运行自动建立项目 `.venv/`，仅安装 `requirements-literature.txt` 的最小依赖与 Chromium；沿用系统 `HTTP_PROXY` / `HTTPS_PROXY` 环境变量，安装或网络失败会明确报错。
- 每次运行在 `.workbench/literature/<任务 ID>/` 保存阶段记录和候选 JSON/CSV；页面按真实阶段显示状态并提供下载，不显示虚构的百分比。
- 结果是实际检索页面或 PubMed 官方接口返回的题录、来源链接、片段或摘要，保留 `source_key` 和实际 transport；PubMed 另保留真实 PMID。全部标为待核查，不自动纳入；页面片段标为 `search_result_snippet`，接口摘要也不能作为全文参数证据。

## 合并后的完整获取流程（2026-10-15）

“只找候选文献”是折叠的辅助入口。下载或文献挖掘模块的“按审核方案开始执行”则运行独立完整流程：方案解析 → Europe PMC/Crossref/Google Scholar 检索 → 首批筛选 → 开放全文或上传材料 → 带证据提取 → 人工核查 → 清洗交接。必须审核方案后执行，首批最多 20 条候选、3 篇全文；未指定 Scholar 的旧方案仍默认 Europe PMC/Crossref。按 DOI/规范化题名去重并保留来源检索记录。

完整流程复用 Scholar 连接器，保留冻结配置与候选文件，验证码暂停后人工验证续跑。Scholar 片段不充当全文证据；数值须在实际材料位置和逐字引文中校验，缺失或冲突留空待讨论。材料获取失败可补传或明确跳过；修改方案需重新审核并启动新批次。CSV 是当前交接格式，尚未自动生成上述规划中的全部 Excel 工作簿。

## 后续范围

主题数据字典的完整校验、SOC 专用数据库自动合并、OCR/图像估读与全量检索仍未实现。项目根目录的 `requirements.txt` 是全局依赖规划清单；「编辑依赖」不会自行安装软件。Scholar 的最小检索环境例外，会准备 `.venv/` 与 Chromium；Windows 支持读取已启用的系统 HTTP 代理。

## 六阶段入口实现进度（上游 2026-10-15，本地整合 2026-10-19）

第二阶段六阶段流水线已接入网页（设计见 `docs/literature-mining-stage2-design.md`，接口契约见 `docs/contract.md` §21）：

- **已实现**：分批候选检索（累计候选、`GSC-###`/`GSC-B<n>-###` 编号）、跨来源 DOI/标题归并去重（明确重复自动合并、疑似重复保留待复核）、全文获取（HTML 优先/PDF 备选，付费墙等标“待补充”）、提取前字段含义与单位确认关口、逐篇可追溯参数提取（7 键契约 + 溯源格式 + 禁推断清单）、阻断/待审核两级校验、文献表与参数明细表 CSV+Excel 导出（同任务重导出归档不覆盖）、任务级事件流水 `events.jsonl`、断点续跑与 `advance` 续跑。
- **仍未实现**：用户上传清单/链接/本地 PDF 的自动导入（仅预留 `source_key="user-upload"` 数据位）；图表像素读数（`figure2data` 不接入网页线，人工转录行可按溯源格式补录）；目标数量达标 gate（阈值语义未对齐，仅预留适配接口）；代理自动发现。

项目根目录的 `requirements.txt` 是全局依赖规划清单；「编辑依赖」不会自行安装软件。检索来源接入方式 = 在 `tools/literature-sources.json` 把条目 `state` 改为 `executable` 并提供同 NDJSON 协议的适配器，阶段脚本无须改动。

## 多来源与人工登录（2026-10-19）

- 六阶段同一任务按选择的六来源逐个检索。测试每来源最多10条；正式按所选上限自动翻页，每页先保存。某来源第N页等待登录也保留该来源前N−1页及前面的来源，后续跨来源去重保留原始来源记录。默认检索预算随来源数、正式目标数量扩展，登录等待会立即保存并退出检索进程。
- 官方页面要求登录、验证码、机构访问权限或出现无法识别的结果页时，展示真实来源与问题。研究者点「打开登录/检索页面」在检索浏览器操作，再点「检查并继续」；服务端重新检查后从原任务当前来源继续。不会以阻拦页作为零命中，也不会代填凭据或自动解验证码。
- 个人账号登录与数据库访问、全文访问权限分别判断。平台接口不接收或导出密码、Cookie、SSO 令牌；浏览器登录状态留在本机检索会话中。
- 配置冻结包含各来源独立检索式、模式及目标数量。配置变化后开启新任务，不能混用已有成果；检查继续明确使用当前阶段边界，“仅检索候选”不会因恢复登录而隐式运行到导出。历史任务重新载入原冻结配置与边界。
- 页面模板、登录等待、同任务恢复与来源结果保存使用可注入测试验证；未以测试替代具体知网/WOS 账户、学校订阅及授权网络中的实际检索验证。

## 补齐六来源（2026-10-19）

- 万方与 Scopus 使用对应官方检索页的实际结果；Scopus 使用 Documents 的 Title Abstract Keywords 字段。需要登录、验证或授权时暂停，操作方式与知网/WOS 一致。
- PubMed 优先调用 NCBI ESearch/EFetch 的固定官方接口，公开检索通常无需登录；限制条数、请求大小、超时与无 Key 请求速率。保留 PMID、DOI、作者、发表年、期刊与公开全文链接，缺失值不推测。
- PubMed 首批接口失败可改走同来源官网；一旦开始分页，锁定API或网页传输，避免不同每页条数造成漏项。后续API失败按原offset重试；未知布局或网络错误不能当作合法零命中。
- 页面提供六来源独立检索式例词，不自动勾选全部来源。来源和查询变更须新任务；已有三来源任务与阶段产物继续恢复。实际受限账号站点的检索可用性取决于当前布局与合法访问权限，测试样本不等于已用研究者账号完成真实检索。
