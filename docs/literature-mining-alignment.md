# 文献挖掘：已确认的输入与默认规则

本文件记录研究者在 2026-10-12 至 2026-10-13 对通用文献挖掘流程的确认。它是后续实现依据，不表示网页已能自动检索、提取或导出。

## 最小启动与阶段关口

- 首批候选检索只需研究主题。默认来源为 Google Scholar，首批最多 10 条；检索结果的标题和片段只能用于初筛，不能当成已核实的论文摘要或全文证据。
- 年份、地区、语言、文献类型和目标数量可选。留空表示不限制；未提供目标数量时仅运行首批，之后由研究者决定是否继续。
- 全文提取前，研究者须确认主题参数字段的含义和单位处理方式。若某主题需要专属硬性纳排规则，也须明确确认。SOC 规则仅在选择 SOC 示例配置时启用。

## 通用筛选与数据结构

- 仅将明确重复或明确不相关的候选自动排除；证据不足时标为“待全文核查”，不强行纳入。
- 文献表一篇论文一行：题名、作者、年份、DOI、来源链接、全文链接、检索日期、筛选状态与理由等通用 meta 字段。
- 参数明细表一个有出处的报告值一行，用论文 ID 关联；保存参数名称、原值、原单位、出处与适用条件。地点、处理、年份等条件按主题定义，不固定为 SOC 结构。
- AI 可提出主题参数候选字段，但字段名称、含义和单位处理须经研究者确认后用于全文提取。
- DOI/题名清单、链接和本地 PDF 是可选输入，与检索结果采用同样的查重、筛选规则；用户提供的材料不自动视为已纳入。全文无法合法获取时标为待补充，不绕过访问限制。

## 校验与导出

- 阻断：缺少论文 ID 或可追溯来源；参数行缺名称或原值；声明为数值的字段不是有效数字；字段不符合本次确认的结构；参数行无法关联文献。
- 待审核：缺 DOI、单位不明、疑似重复或异常值。不擅自补值、换算或删除。SOC 数值范围等科学阈值不作通用默认。
- 默认依据同一份已确认字段定义生成文献表与参数明细表，均导出 CSV 和 Excel。被排除文献仍保留筛选记录；校验失败的行另列错误报告；新结果不覆盖旧版本。
- 用户 Excel 模板可选；若提供，先核对并确认字段映射。SOC 模板的两张固定工作表与专属字段不直接套用到其他主题。
