# 科学问题凝练与提取工作流（讨论草稿 v0.1）

> 九步研究流程 · 环节②。对应业务流程表「科学问题凝练与提取：结合文献讨论研究空白，确定要回答的问题」。
> 上游是环节①文献调研（研究空白清单），下游是环节③数据获取与清洗。

## 定义

把文献调研得出的研究空白，收敛成一个可回答、可检验的科学问题，并明确其研究对象、
关键变量、边界条件与预期贡献。问题必须与空白一一对应，不允许凭空另起问题。

## 输入

- 必需：上游环节①交付的文献清单、综述要点、研究空白清单（含溯源依据）。
- 可选：可用数据与实验条件（若已知）、已有初步想法、目标期刊偏好的问题表述粒度。
- 研究者本人已有的结论倾向（若有，需与文献证据对照，不得直接采信）。
- 上游空白尚未定稿时，先对齐空白再凝练问题，不基于未定稿空白继续推进。

## 执行

1. 逐条读取空白清单，剔除不成立或与本方向无关的空白，保留可研究的条目。
2. 对每条保留空白，评估可回答性：需要什么数据、方法上是否可行、能否被证伪。
3. 从可回答性最高的空白中凝练问题，写成一句话问题陈述。
4. 拆解问题：研究对象、关键变量、变量间关系、边界条件、对照与参照。
5. 转为可检验形式（假设 / 可证伪陈述），明确什么结果算支持、什么算否定。
6. 说明研究价值与预期贡献：补上哪一块空白、可能对谁有用、与已有工作的区别。
7. 逐条核对：问题的每个组成部分都能回指到文献依据；无依据的成分删除或标注为假设。
8. 交人工审阅；被否定的空白与理由一并留存，供回溯。

## 交付

- 一句话科学问题陈述（含可检验形式）。
- 研究对象、关键变量、边界条件、对照参照的分解说明。
- 与文献空白的对应表：问题组成部分 ← 支撑空白 ← 溯源文献。
- 可行性说明：需要的数据与方法、预期主要不确定性、可能失败的情形。
- 预期贡献表述（用于后续文章引言与讨论）。
- 未采纳的空白及理由。

## 检查

- 问题可被检验：写得出支持与否定两种结果。
- 变量与边界条件清晰，无「效果」「影响」一类无法操作的表述。
- 问题与文献空白一一对应，每个组成部分都有出处。
- 可行性与本机实际可获得的数据 / 算力相符。
- 未把个人偏好当作问题来源，偏好只影响表述方式。

## 异常

- 空白无法收敛成一个问题：说明是多个独立问题还是问题本身不成立，给出拆分或放弃建议。
- 问题与方法不匹配：说明需要换方法还是换问题，不强行推进。
- 所需数据不可得：如实指出缺口，提出可行的替代变量或替代数据源。
- 多个问题同样成立：给出优先级依据（可回答性、贡献、数据可得性）并交人工选择。
- 凝练结果与已有工作重复：回到空白检查，定位被忽略的差异点。

## 需对齐内容

1. 问题的表述粒度：一句话陈述，还是同时给结构化分解（本环节已两者都给，是否都要写进文章）。
2. 可行性评估由谁做：AI 初判后人工确认，还是必须由导师确认后才算通过。
3. 是否强制要求「可证伪」——部分综述型研究可能不适合该形式。
4. 多个候选问题是否允许并存推进。
5. 凝练环节是否需要产出给导师汇报用的简短版本。
