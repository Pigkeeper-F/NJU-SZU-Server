# 计算工作流（讨论草稿 v0.1）

## 定义

使用指定且已确认的计算方法，根据活动数据和参数数据生成结果。支持直接计算，以及接入参数更新/活动数据更新后的计算；更新输入时记录版本，保证计算过程可复现。

## 输入

- 必需：计算程序、输入数据、字段说明。
- 直接计算：提供符合现有输入约定的数据和参数。
- 接入更新模块：提供新数据/参数、旧版本及数据对齐要求。
- 可选：运行环境、随机种子、精度、资源限制、基准结果、预期趋势与验收条件。
- 未明确方法或字段语义时先形成待确认项，不能仅按字段名相似自动映射。

## 执行

1. 识别计算方式，确认方法版本、输入版本和运行配置。
2. 核对输入字段、单位、时间/空间尺度、分类与参数适用范围。
3. 直接计算时检查既有输入约定；接入更新模块时形成字段/语义对齐文档，记录连接键、转换、聚合及缺失处理，经确认后形成对齐代码。
4. 保存本次运行配置与输入快照，运行既定计算程序。
5. 检查结果结构、数值状态、守恒/边界关系及与基准的差异（适用时）。
6. 交付结果并进入人工审核；问题按输入数据、参数、对齐、运行代码分别定位和回退。

## 交付

- 计算结果数据、字段与单位说明。
- 方法/程序版本、输入与参数版本、对齐文档及代码、运行配置和日志。
- 自动检查结果、基准差异、失败记录与待审核事项。
- 可交给绘图的结果数据及可用维度说明。

## 检查

- 输入与方法约定匹配，连接键和连接基数正确，无意外多对多扩增。
- 输出数量、范围、缺失、无穷值等符合验收条件。
- 适用的守恒、汇总或边界关系成立；基准差异能说明来源。
- 同一输入、配置和环境可复现；随机过程记录种子及适用的误差容限。

## 异常

- 输入不匹配、单位或映射含糊：暂停受影响计算，返回对齐待确认项。
- 参数超出适用范围：标记并交人工决定，记录替代方案或外推依据。
- 程序失败或资源不足：保存错误和已完成范围，调整执行方案后重跑。
- 结果异常：定位输入、参数、对齐或代码原因，回到对应模块处理；保留前后版本。

## 需对齐内容

1. 首期使用哪些计算方法/程序，如何登记和选择？
2. 直接计算是否始终保持方法不变，方法调整应进入哪个流程？
3. 参数更新和活动数据更新能否同时接入一次计算？
4. 对齐文档需要人工确认哪些内容，是否包含新模块注册？
5. 哪些数值检查与基准差异构成阻断，哪些只提示？
6. 当前界面模块顺序与业务上的“更新/审核后再计算”如何对应，是否支持回流与重新运行？
