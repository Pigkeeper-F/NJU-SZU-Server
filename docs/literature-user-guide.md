# 文献五库下载 · 使用者操作指南

面向第一次使用本平台下载文献的同学。按顺序照做即可完成「登录 → 检索 → 全文下载」；遇到问题时先看第 6 节，仍解决不了可以直接在 AI 对话里提问。

---

## 1. 启动与进入

1. 在项目目录运行 `npm start`（或双击 `start-workbench.cmd`），浏览器打开 `http://localhost:8123/`。
2. 首次访问需注册：注册页输入测试码（定义在 `js/auth-config.js`），再设置账号密码；也可以点「测试直达（免登录）」先体验。
3. 平台数据存在浏览器本地，服务重启不丢；换浏览器或换端口需要重新登录。

## 2. 新建文献任务

1. 左侧栏点「任务」展开 → 点「**＋ 新建任务**」。
2. 填「任务名称」，「从哪一步开始」选 **文献挖掘** → 点「创建任务」。
3. 左侧「研究空间（工作台）」→ 点「**文献挖掘**」进入模块。
4. 模块顶部点「**＋ 新建文献任务**」→ 填任务名（例如"肉鸡热应激 · 正式检索"）→ 选「小样测试（每来源10条）」或「正式检索（到可访问末页）」→ 创建。**创建后不会立即检索**，先做第 3 节的登录。

> 建议第一次用「小样测试」走通全流程，再开正式检索。

## 3. 登录五个数据库（文献任务顶部的「账号与权限」面板）

| 按钮 | 作用 | 你要做的事 |
|---|---|---|
| 打开机构登录 | 万方机构入口 | 官方页搜索并选择自己学校 → 统一身份认证 |
| 知网机构登录 | 知网机构入口 | 同上 |
| Web of Science 登录 | 学校图书馆校外通道 | 已登录 EZproxy 则直接进入；过期会跳统一身份认证 |
| Scopus 登录 | 学校图书馆校外通道 | 同上 |
| EZproxy 统一登录 | 学校 EZproxy 总入口 | 登录一次，覆盖校内已订购资源 |
| 打开万方会员 | 个人会员购买（可选） | 机构权限够用就不需要 |
| 检查登录状态 | 逐库显示：已登录 / 未登录 / 仅预览 / 需要多因子 | 登录完点它确认 |

要点：

- 登录只能在**平台专用浏览器**的官方页面里完成；普通浏览器不共享登录态。
- 万方勾「7天免登录」约 7 天有效；其他库按各自会话有效期，过期重登即可。
- WoS / Scopus 的登录走学校 accproxy 校外通道，**一次 EZproxy 登录同时覆盖两者**。
- Google Scholar 无需登录。
- 平台不代填账号、不代付款；付费墙和验证码如实暂停，不绕过。

## 4. 配置检索并开始

1. 展开文献任务里的「本次检索设置（点击查看或修改）」。
2. 勾选来源（Google Scholar / 知网 / 万方 / Web of Science / Scopus，可多选）；每个来源可以单独填检索式，知网、万方可直接写中文。
3. 选「小样测试」或「正式检索」→ 按提示完成**逐项核查**（研究范围、来源与检索式、纳排与交付、执行边界）→ 点「使用已确认配置」。
4. 选「本次做到哪一步」（首次建议做到 `discover` 检索候选）→ 点「**开始检索**」。

## 5. 撞到登录墙 / 验证码怎么办

任务会**暂停并保留已有结果**，不会丢：

1. 切到平台专用浏览器，在官方页面完成登录 / 滑块 / 验证码。
2. 回工作台点「**检查并继续**」，任务从原位置继续。
3. 检索完成后点「**继续下一阶段**」依次推进：去重 → 全文获取 → 参数提取 → 校验 → 导出。
4. 全文阶段在「每篇材料清单」看逐篇状态（PDF / HTML / 待补充）；失败原因和已存文件都有记录。

## 6. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 万方提示滑块验证 | 会话过期（约 7 天），在专用浏览器完成滑块或重新机构登录 |
| 知网提示同名文献多个版本 | 平台按安全规则不猜，请在原页面人工确认目标文献后重试该篇 |
| WoS / Scopus 显示"未登录 / 仅预览" | 点面板对应登录按钮走学校校外通道；或先点「EZproxy 统一登录」 |
| 知网返回 CAJ 而非 PDF | 平台只收 PDF；CAJ 样本暂不支持自动下载，保留人工处理 |
| 学校没订的出版社论文 | 会记录 `access_required` 暂停，属正常边界，平台不绕过订阅 |
| AI 对话提示 Codex 未连接 | 平台已自动改用 API 对话（服务端 .env 凭据），可直接继续提问 |

## 7. 问 AI 帮忙

文献挖掘模块的对话区就是 AI 助手（工作台默认接「本机 Codex」，未连接时自动改用「API 对话」，无需配置）。

- 直接问："我第一次用，不知道怎么登录知网" —— AI 会给出步骤，**回复下方会自动弹出登录按钮面板**，点按钮即可打开官方登录页。
- 也可以问："检查一下现在各库的登录状态"、"帮我看看这篇为什么没下载到"。
- 涉及科学判断（纳入/排除标准、字段含义、单位）AI 会先和你确认，不会替你定规则。

## 8. 平台边界（必读）

- 只在官方页面登录，平台不读不存账号密码，不代付，不绕过订阅墙、验证码、下载配额。
- 学校未订购的内容会如实记录 `access_required`，不会伪装成下载成功。
- 小样/首篇成功不代表全量完成；正式批次结果以任务目录里的 `fulltext/status.json`、材料清单与导出 CSV 为准。
- 实现状态与技术细节见 `docs/literature-five-source-status.md`。
